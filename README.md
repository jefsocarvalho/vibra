# VIBRA Web App

Aplicação web criada com Next.js e Tailwind CSS para guiar usuárias a equilibrar energia emocional, elevar sua vibração e cultivar hábitos positivos.

## Scripts

- `npm run dev` – inicia o servidor de desenvolvimento.
- `npm run build` – gera build de produção.
- `npm run start` – roda o servidor em modo produção.
- `npm run lint` – executa ESLint.
- `npm run format` – aplica Prettier.

## Principais áreas

- Landing page com destaque dos recursos principais, depoimentos, preços e programa de indicações.
- Fluxo de autenticação e onboarding com coleta de intenções.
- Dashboard com diário energético, desafio de 21 dias, modo prosperidade, zona premium e painel de indicações.

Os componentes foram estruturados de forma objetiva e otimizada para uso no Framer, respeitando a paleta lavanda, branca e dourada.
